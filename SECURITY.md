# Security & Data Protection Policy

## Research data

This repository **does not contain** and **must never contain**:
- Student survey responses (raw or processed)
- Personal identifiers (names, ages linked to identities)
- School-level identifiers that could identify individuals
- Timestamps that could be used to re-identify respondents

## Reporting a data exposure

If you discover that sensitive data has been accidentally committed:
1. **Do not** open a public issue
2. Contact the repository owner immediately via LinkedIn:
   [Chancelline Armelle Nongni Kendjio](https://www.linkedin.com/in/chancelline-armelle-nongni-kendjio-9840582b/)
3. We will remove the data and rotate any affected credentials within 24 hours

## Branch protections

The `main` branch is protected:
- Direct pushes are disabled
- Pull requests require at least 1 review
- All status checks (tests) must pass before merge
